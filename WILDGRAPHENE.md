# WildGraphene

Custom GrapheneOS kernel builds for Pixel Tablet (`tangorpro`) with the
SUSFS-integrated KernelSU-Next fork. Everything stays in this repository.

Use **WildGraphene - upstream builds and OTA preparation** (`tangorpro-ota.yml`)
to track current GrapheneOS, KernelSU-Next/SUSFS commits, build matching kernel
and modules, and prepare OTA inputs. AVB/OTA signing remains local. Custota release
assets and metadata are generated by the local signing/publishing scripts.

See [OTA_AUTOMATION.md](OTA_AUTOMATION.md) for setup and the exact boundaries
between automatic builds, local signing, hardware testing, and publishing.

**GrapheneOS tangorpro - KernelSU-Next SUSFS** (`graphene-tangorpro.yml`) reproduces
the original pinned kernel snapshot. It does not track newer versions.

The older generic Wild Kernels workflows are retained as imported infrastructure;
they are not the GrapheneOS tablet update pipeline. Their upstream license remains
under `third_party/wild-kernels`; the root LICENSE is preserved. No Telegram
credentials or private signing keys belong in the repository or Actions.

Current hardware status: custom kernel compilation, OTA packaging, and local OTA
signing/verification have passed for the initial release. Device booting and
Custota installation/update tests are still pending.
